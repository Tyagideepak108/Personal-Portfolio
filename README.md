# Deepak Tyagi - Portfolio Website

A modern, responsive portfolio website showcasing my skills as an AI/ML Developer and Software Engineer with dynamic dark mode and glassmorphism effects.

## 🚀 Live Demo
[View Portfolio](https://deepak-portfolio-25.vercel.app)

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Grid, Flexbox, Glassmorphism, Custom Animations
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins)
- **Form**: FormSubmit.co Integration

## ✨ Features
- 🌓 **Dark/Light Mode Toggle** with localStorage persistence
- 📱 **Fully Responsive Design** (Mobile, Tablet, Desktop)
- 🎨 **Modern UI/UX** with Purple-Blue Gradient Theme
- 💎 **Glassmorphism Effects** on cards and navbar
- 🌟 **Interactive Elements** with smooth hover effects
- 📊 **Animated Skill Progress Bars**
- 🎯 **Smooth Scrolling Navigation**
- 📧 **Contact Form** with direct email integration
- 🔄 **Loading Animations** and transitions
- 📈 **Scroll Progress Indicator**
- ⬆️ **Back to Top Button**
- 🖼️ **Profile Image** with zoom effect
- ✨ **Particle Effects** in hero section
